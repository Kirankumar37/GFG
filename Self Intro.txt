Project Experience: I’d like to share details about a team project I worked on titled Energy Management in Commercial Facilities. In this project, we created a prototype for a boardroom meeting using technologies like Raspberry Pi, ESP32, camera module, voltage and current sensors, LED displays, and basic sensors. The key functionality of the system involves human presence detection: When someone opens the door, a Hall Effect sensor triggers the ESP32, which turns on the lights and activates the camera module. The camera identifies the number of people in the room, and this data is sent to the Raspberry Pi. Using the MQTT protocol, the Raspberry Pi communicates this data back to the ESP32, which controls the lights via relay modules. We also integrated a trailing edge dimmer circuit to adjust the light intensity based on the analyzed data and created a user interface to display power usage for energy conservation analysis.
